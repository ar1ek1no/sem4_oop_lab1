# Документация проекта: что где лежит

Проект «Управление финансовой системой» — база для пяти лабораторных по верификации ПО.
Документы разложены по папкам лабораторий, чтобы можно было открыть нужную папку и увидеть
ровно то, что требует задание.

| Папка | Лабораторная | Что внутри |
|---|---|---|
| [`lab1/`](lab1/) | Требования (ЛР1) | README проекта лежит в корне, плюс `SRS_finance.md`, `STATE_DIAGRAM.md`, `ISSUES.md` |
| [`lab2/`](lab2/) | Тесты и покрытие (ЛР2) | `COVERAGE.md`; сами тесты — в [`../tests/`](../tests/) |
| [`lab3/`](lab3/) | План, кейсы, дефекты (ЛР3) | `TEST_PLAN.md`, `CHECKLIST.md`, `TEST_CASES.md`, `TEST_RESULTS.md`, `DEFECT_REPORTS.md`, `screenshots/`, лог прогона |
| [`lab4/`](lab4/) | Вёрстка, API, безопасность, UI (ЛР4) | `COMPATIBILITY.md`, `API_TESTING.md`, `SECURITY.md`, `postman/`, отчёт newman |
| [`lab5/`](lab5/) | Нагрузка, линтер, трассируемость (ЛР5) | `LOAD_PLAN.md`, `LOAD_RESULTS.md`, `LINTING.md`, `TRACEABILITY.md`, `load/` |
| [`_internal/`](_internal/) | Служебное | журнал изменений `BLOCKS.md`, разведка `AUDIT.md`, план блоков, методичка, стартовый промт |

Начать изучение лучше с [`../СДАЧА.md`](../СДАЧА.md): это оглавление шести гайдов.
Сами гайды — в [`../readmes/`](../readmes/): план и по одному файлу на каждую лабораторную.
